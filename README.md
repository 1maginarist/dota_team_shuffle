# Dota Team Shuffle: Telegram-бот

Бот делит компанию друзей на две сбалансированные команды Dota 2 и раздаёт позиции с 1 по 5.

## Как этим пользоваться

**Игроки** один раз регистрируются в личке с ботом:

1. `/start` → прислать свой ММР числом, например `4500`.
2. Выбрать роли **по приоритету**: нажимать позиции от самой любимой. Роли, которые не выбрал, бот считает «не хочу».
3. После регистрации игрок **онлайн**, то есть виден организатору. Статус держится, пока игрок сам его не выключит: `/offline` (или кнопка в `/profile`). Включить обратно можно через `/online`.

**Организатор**:

1. Пишет `/game` в личке с ботом или в общем чате, если бот туда добавлен.
2. Видит список всех, кто онлайн. Сам организатор уже отмечен. Нажимает на игроков, чтобы отметить, кто играет. Кнопка «Показать всех» добавляет в список и оффлайн-игроков.
3. Нажимает **⚖️ Распределить**, и бот присылает составы:

```
🌞 Свет — Σ 22 900 · ср. 4 580
1️⃣ Керри — Артём · 3 300 ⭐
2️⃣ Мид — Гоша · 5 300 ⭐
3️⃣ Оффлейн — Петя · 4 000 ⭐
4️⃣ Семи-сап — Ваня · 3 900 (2-я)
5️⃣ Фулл-сап — Дима · 6 400 ⭐

🌚 Тьма — Σ 22 800 · ср. 4 560
...
⚖️ Разница: 100 ММР
🪑 Скамейка: Саша
```

4. **🔀 Другой вариант** показывает другое разбиение, если этот состав не нравится. **✅ Утвердить** фиксирует состав, и каждый игрок получает в личку свою команду и позицию.

Сколько человек ни отметишь, бот разберётся:

- **9 человек**: команды 5 на 4, в меньшей одна позиция остаётся пустой.
- **Больше 10**: лишние идут на скамейку. Первыми садятся те, кто не сидел в прошлый раз, а среди равных те, кого отметили последними. Кто сидел на скамейке, в следующей утверждённой игре играет в приоритете.
- **Меньше 10**, например 3 на 3 или 4 на 4: тоже работает.

## Как бот балансирует

Бот перебирает **все** разбиения на две команды (для 10 человек их 126). Внутри каждой команды он перебирает все раскладки по позициям (120 штук). Каждому варианту считается стоимость:

```
стоимость = |ΣММР Света − ΣММР Тьмы| + штрафы за роли
```

Штрафы считаются в «ММР-эквиваленте»:

| Игрок стоит на…           | Штраф |
|---------------------------|-------|
| своей 1-й роли            | 0     |
| 2-й по приоритету         | 100   |
| 3-й                       | 250   |
| 4-й                       | 400   |
| 5-й                       | 600   |
| роли, которую не выбирал  | 1500  |

Например, бот скорее согласится на лишние 100 ММР разницы, чем поставит человека на его вторую роль. Не на свою роль он ставит, только если иначе совсем никак. Перебор полный, поэтому найденный вариант действительно лучший по этой формуле. Веса настраиваются в `.env`.

## Запуск на VPS

Понадобятся Linux-сервер, `git` и Docker с плагином compose. Если Docker не установлен, поставь его командой `curl -fsSL https://get.docker.com | sh`.

1. В Telegram открой [@BotFather](https://t.me/BotFather), отправь `/newbot` и скопируй токен.
2. На сервере выполни:

   ```bash
   git clone https://github.com/1maginarist/dota_team_shuffle.git
   cd dota_team_shuffle
   cp .env.example .env
   nano .env                     # вписать BOT_TOKEN=...
   docker compose up -d --build
   docker compose logs -f        # убедиться, что бот запустился (Ctrl+C — выйти из логов)
   ```

3. Напиши боту `/start` и проверь, что он отвечает.
4. Если собирать игру должен только ты: напиши боту `/id`, впиши полученное число в `.env` как `ADMIN_IDS=123456789` и перезапусти бота командой `docker compose up -d`.
5. По желанию добавь бота в общий чат, чтобы делать `/game` там. Нажимать кнопки в меню сможет только тот, кто его открыл.

Бот работает через long polling, поэтому домен, HTTPS и открытые порты не нужны. Контейнер сам поднимается после перезагрузки сервера.

**Обновление:** `git pull && docker compose up -d --build`
**Бэкап:** вся база лежит в одном файле `data/bot.sqlite3`.

## Команды

| Команда            | Где          | Что делает                                         |
|--------------------|--------------|----------------------------------------------------|
| `/start`, `/profile` | личка      | регистрация / профиль с кнопками «Изменить»        |
| `/mmr 4500`        | личка        | поменять ММР (или просто прислать число)           |
| `/roles`           | личка        | заново выбрать роли                                |
| `/online`, `/offline` | везде     | показываться ли организатору                       |
| `/game`            | везде        | собрать игру (организатор)                         |
| `/players`         | везде        | все зарегистрированные игроки и их статус          |
| `/id`              | везде        | свой Telegram ID для `ADMIN_IDS`                   |
| `/help`            | везде        | справка                                            |

## Настройки `.env`

| Переменная            | По умолчанию           | Зачем                                                    |
|-----------------------|------------------------|----------------------------------------------------------|
| `BOT_TOKEN`           | —                      | токен от @BotFather (обязательно)                        |
| `ADMIN_IDS`           | пусто (любой)          | кто может делать `/game`, ID через запятую               |
| `ROLE_PENALTIES`      | `0,100,250,400,600`    | штраф за 1-ю…5-ю роль из списка игрока                   |
| `OFF_ROLE_PENALTY`    | `1500`                 | штраф за роль, которую игрок не выбирал                  |
| `RESHUFFLE_TOLERANCE` | `200`                  | насколько «Другой вариант» может быть хуже лучшего       |
| `DB_PATH`             | `data/bot.sqlite3`     | где лежит база                                           |

## Разработка

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
pytest                                  # тесты алгоритма + сквозной сценарий бота
BOT_TOKEN=... python -m bot             # запуск локально
```

Структура:

- `bot/balancer.py`: алгоритм балансировки, без зависимостей от Telegram
- `bot/handlers/profile.py`: регистрация, ММР, роли, онлайн/оффлайн
- `bot/handlers/organizer.py`: меню выбора игроков, распределение, утверждение и рассылка
- `bot/db.py`: хранилище SQLite
- `bot/texts.py`, `bot/keyboards.py`: тексты сообщений и кнопки
